# ChordLab Android v0.4.0

Nueva interfaz basada fielmente en las últimas pantallas visuales acordadas.

## Cambios principales
- Pantalla principal Portrait recreada con cabecera ChordLab, pestañas, idea, emociones, estilo/tonalidad/tempo y propuestas 2x2.
- Pantalla de propuesta Portrait recreada con navegación superior, progresión, transporte, instrumentos, patrón rítmico y panel didáctico contraído.
- Eliminados Variar y Similar de la propuesta.
- Patrón rítmico ocupa el espacio de esos controles y ofrece 3 opciones.
- ¿Por qué funciona? permanece contraído por defecto y es desplegable.
- Iconos de Piano/Bajo son pulsables y abren selector de instrumento.
- Recuperadas las opciones de instrumentos de la primera versión, manteniendo Piano acústico y Bajo eléctrico como valores iniciales.
- Se mantiene SpessaSynth + GeneralUser GS local de las versiones anteriores.
- Se conserva el motor armónico, exportación, favoritos, Crear y Estudio de la v0.3.0.

## Compilación
Usar el mismo workflow GitHub Actions del repositorio ChordLab. No se ha modificado `.git` ni `.github`.
