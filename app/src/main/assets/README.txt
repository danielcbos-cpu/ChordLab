ChordLab Android v0.2.1 — Portrait UI
======================================

Actualización visual de ChordLab Android v0.2 para teléfonos en orientación vertical.

Cambios principales:
- Cabecera específica para portrait, más compacta y sin solapamientos.
- Marca ChordLab y versión reorganizadas en una fila limpia.
- Iconos secundarios de cabecera ocultos en móvil para reducir ruido visual.
- Instrumentos 1 y 2 mantienen una composición simétrica.
- Nombres visibles simplificados: Piano acústico / Bajo eléctrico.
- Sliders de volumen sin porcentaje: el propio recorrido representa 0–100 %.
- Sliders más largos y cómodos para uso táctil.
- Caja de complejidad de propuestas compactada.
- Landscape conserva la composición de la v0.2.
- Se mantienen SpessaSynth, GeneralUser GS, motor armónico y sustituciones táctiles.
- Safe areas de Android conservadas.

Uso con HTML to APK Builder:
1. Importa este ZIP.
2. Usa index.html como página inicial.
3. Activa JavaScript.
4. Orientación recomendada: Landscape + Portrait, si el constructor lo permite.
5. Nombre: ChordLab.
6. Versión: 0.2.1.
